# IBS-0002 — Adapter protocol

Status: draft 0.1, proposed. Language-neutral subprocess adapter is the initial reference transport; native integrations may follow.

Handshake returns protocol version, implementation name/version/build digest, supported operations, formats, parameter schema, threading controls, dictionary support, streaming and access capability, and declared resource needs. Negotiate version before execution; unsupported operations return typed status rather than emulation.

Operations: describe, encode, decode; optional list, extract, stream and range-read. Requests carry unique ID, operation, input/output references in harness-owned workspace, explicit configuration and resource budget. Responses carry matching ID, status, consumed/produced byte counts and diagnostics. Harness independently verifies sizes, duration and reconstruction; adapter-reported metrics must be distinguished from harness observations.

Use structured UTF-8 JSON messages with bounded framing; exact wire framing and binary transport remain to be specified. Launch with argument arrays, never shell splitting. Keep diagnostic output separate. Worker timeouts and cancellation must terminate owned processes; no uncontrolled output paths. Do not allow an adapter to overwrite source corpus or preexisting user files.

Conformance fixtures: handshake mismatch, unsupported operation, malformed reply, output size discrepancy, nonzero exit, timeout, missing output and incorrect reconstruction. External tool import is a distinct producer interface, not an execution adapter.

## Whole-artifact completion

A whole-artifact decode reports success only after processing the complete artifact according to the declared format profile. End of one gzip member or Zstandard frame is a progress event. The runner must retain success/failure separately from stdout, because an adapter can emit bytes before a later failure. Decoder-reported completion and consumed bytes are checked against the harness's artifact and expected output. The bounded framing and failure vocabulary for the adapter transport remain under review.

[Format vectors](../conformance/vectors.json) exercise concatenated members and frames, skippable frames and a truncated final frame.

The [trusted local worker](../worker/README.md) uses one built-in gzip adapter with an owned POSIX process group and a private diagnostic transport. The language-neutral handshake and stable wire format remain under review.
