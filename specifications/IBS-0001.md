# IBS-0001 — Execution and measurement

Status: draft 0.1; proposed, not implemented. MUST/SHOULD denote draft requirements.

1. Run identity MUST bind corpus digest, adapter and build identity, configuration, profile version, worker environment and schedule seed.
2. Comparison classes MUST distinguish memory, stream, file and archive operation; timed boundaries MUST match within a comparison. Record initialization, allocation, I/O, finalization and thread budgets.
3. Use a monotonic elapsed clock; record units and resolution. Nonpositive measured durations MUST be flagged, not used as rates. Batch observations MUST retain total work, elapsed duration and invocation count; do not combine individual and batch estimates as independent observations.
4. Warm-up MUST be labeled and excluded from primary sampling. Use seeded balanced/randomized blocks for comparable configurations; record actual order and interruptions.
5. Minimum duration and iteration budgets MUST be explicit. Precision-based stopping requires a separately specified estimator and stopping rule. Preserve raw trials and independent worker/block identifiers.
6. Exact reconstruction MUST qualify competitive lossless results. Report validation cadence; compression-only or unverified results MUST not receive qualified rankings. Validation time is separate unless profile explicitly includes it.
7. Workers MUST have timeouts, exclusive scratch directories, and documented resource controls. Process isolation does not imply secure sandboxing. Untrusted adapters require additional containment.
8. Failed trials MUST remain visible. Record typed status; do not encode errors as zero performance.
9. Report environment, clock, cache policy, CPU topology, OS, compiler, flags, codec versions and binary hashes. Unsupported probes MUST be explicitly unavailable.
10. Report aggregate estimator and uncertainty method; no cross-machine equivalence claims without an explicit comparison model.

Acceptance: deterministic fake adapter fixtures for timing, finalization, timeout, intermittent invalid output, order, zero duration, and batch sample accounting. See research/runner-source-review.md. Statistical precision and platform probe semantics remain unresolved.
