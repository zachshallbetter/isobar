# IBS-0004 — Metrics and scoring

Status: draft 0.1, proposed. See [scoring mathematics](../research/scoring-mathematics.md).

Raw bytes and elapsed time remain authoritative. Ratio = input/output; savings = 1-output/input; throughput = work bytes / elapsed seconds. Undefined denominators return typed unavailable status. Empty inputs retain sizes and correctness results. Aggregate ratio uses total input / total output; aggregate serial throughput uses total work / total time. Report MB as decimal and MiB as binary.

Count complete format artifacts and required model/dictionary dependencies; report external shared overhead separately with a declared amortization policy. Keep codec and archive accounting distinct.

Historical Weissman: alpha*(R/R0)*ln(T0)/ln(T). Pin units, baseline, alpha and estimator. Reject nonfinite/nonpositive inputs and singular denominator. Label known nonmonotonicity and unit dependence; do not silently change formula.

Composite: 100*exp(sum(w_i*ln(q_i))), where q is candidate/reference for maximization and inverse for minimization. Require finite positive included quantities, nonnegative weights summing to one, matching metric definitions and qualified comparable runs. Exclude zero-weight dimensions. Missing required metric yields unavailable. Compute in log space and handle numerical range explicitly. Baseline 100. Weight profiles are policy, not universal truth.

Pareto: no worse in every selected comparable dimension and strictly better in at least one. Equal points are ties; missing dimensions prohibit comparison. Exact dominance is distinct from uncertainty-aware dominance, which remains open research.

Ordinal rankings depend on candidate set; publish set identity and tie policy, do not mix with absolute normalized scores. A failed or unverified lossless configuration is ineligible for qualified rankings.

Acceptance vectors: identity 100; doubled sole dimension 200; reciprocal ratios at equal weights 100; unit conversion invariance; missing/zero/NaN rejection; invalid weights; Weissman singularity and subunit inversion; Pareto ties and tradeoffs; permutation invariance; disabled dimension tie behavior. No official weight profiles until reviewed.

## Executable metric examples

The [vectors](../conformance/vectors.json) cover totals rather than means of per-file ratios or rates, empty inputs, required values, zero-weight exclusion, unit conversion, overflow/underflow, the historical singularity and inversion, and exact Pareto comparisons. Implement the composite log ratio as a difference of logarithms so that an intermediate quotient cannot overflow before weights are applied. Active dimensions determine exact Pareto dominance. Ordinal UI sorting may use a stable secondary key, while rank equality should depend only on criteria active in the profile.

The checker defines exploratory numeric tolerances for these vectors. Production equivalence, uncertainty-aware dominance and canonical profile identity are unresolved.

## Experimental replay from evidence

The local replay checks one IBS-0003 encode run using `0.1-experimental` observations and their linked validation records. It discards warm-ups. Every measured observation must qualify through the evidence verifier. Each configuration must cover the same worker, block and input slots as the baseline, with equal work and invocation counts in those slots. Duplicate rows for one configuration and slot are invalid. Failed or unmatched observations withhold the comparison. The caller supplies evidence from a serial run. The observed slots alone cannot prove that every planned measurement was captured or that the run was serial.

The archived IBS-0003 records include work and elapsed time. Output size can be recovered in a local replay by supplying one original and complete gzip or Zstandard artifact per recorded invocation, associated with its observation ID. The replay recognizes format magic and checks whole-artifact exact reconstruction and reconciles total original bytes with the observation. When complete artifact sets are supplied across configurations, their original input contents must agree within each slot. The association with the recorded invocation is supplied by the caller. A signed binding between artifacts and observations remains future evidence-format work.

| Version | Rule |
| --- | --- |
| `total-byte-ratio-v1` | Sum work bytes over all measured invocations and divide by the sum of complete artifact bytes, including every member and frame. All invocation artifacts must be present. Zero total original bytes leaves ratio undefined. |
| `serial-bytes-per-second-v1` | Sum work bytes and nanoseconds across measured observations, then divide work by elapsed seconds. Each recorded batch contributes its totals once. Zero total work yields zero throughput. |
| `weighted-log-ratio-v1` | Give ratio and throughput explicit nonnegative weights totaling 10,000 basis points. Both metrics are maximized. Subtract baseline log values from candidate log values before weighted summation and exponentiation. A valid baseline scores exactly 100. Disabled metrics are skipped before checking value availability. |
| `enabled-lexicographic-competition-v1` | Compare exact enabled metric values in ratio-then-throughput order, highest first. Equal enabled values have the same rank, and the next rank skips the tied places. Configuration identifiers order display only. |

Totals are serialized as decimal integer strings, and raw metrics as reduced rational strings. This preserves arithmetic even when an aggregate exceeds the range of interoperable single-record JSON integers. Composite scores use positive finite binary64 output. An unrepresentable score is `out_of_range`. A missing or undefined active metric withholds the ordinal ranking. A zero-throughput metric can be ranked exactly, while a composite that requires it is unavailable. The ordered set of configuration IDs, run ID, baseline, weights, metric versions and referenced observation IDs accompany each replay. The candidate-set identifier in this prototype is the explicit sorted list within the named run.

The replay does not issue historical Weissman scores. A future compatibility profile must pin time units and the baseline before using the historical formula. The ranking produced here is descriptive and experimental. Comparative publication requires qualified format evidence, a reviewed uncertainty procedure and complete matched coverage. The replay keeps publication withheld while those conditions are under review. [Replay and verification commands](../conformance/README.md#replay-qualified-scoring).
