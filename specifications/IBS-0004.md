# IBS-0004 — Metrics and scoring

Status: draft 0.1, proposed. See [scoring mathematics](../research/scoring-mathematics.md).

Raw bytes and elapsed time remain authoritative. Ratio = input/output; savings = 1-output/input; throughput = work bytes / elapsed seconds. Undefined denominators return typed unavailable status. Empty inputs retain sizes and correctness results. Aggregate ratio uses total input / total output; aggregate serial throughput uses total work / total time. Report MB as decimal and MiB as binary.

Count complete format artifacts and required model/dictionary dependencies; report external shared overhead separately with a declared amortization policy. Keep codec and archive accounting distinct.

Historical Weissman: alpha*(R/R0)*ln(T0)/ln(T). Pin units, baseline, alpha and estimator. Reject nonfinite/nonpositive inputs and singular denominator. Label known nonmonotonicity and unit dependence; do not silently change formula.

Composite: 100*exp(sum(w_i*ln(q_i))), where q is candidate/reference for maximization and inverse for minimization. Require finite positive included quantities, nonnegative weights summing to one, matching metric definitions and qualified comparable runs. Exclude zero-weight dimensions. Missing required metric yields unavailable. Compute in log space and handle numerical range explicitly. Baseline 100. Weight profiles are policy, not universal truth.

Pareto: no worse in every selected comparable dimension and strictly better in at least one. Equal points are ties; missing dimensions prohibit comparison. Exact dominance is distinct from uncertainty-aware dominance, which remains open research.

Ordinal rankings depend on candidate set; publish set identity and tie policy, do not mix with absolute normalized scores. A failed or unverified lossless configuration is ineligible for qualified rankings.

Acceptance vectors: identity 100; doubled sole dimension 200; reciprocal ratios at equal weights 100; unit conversion invariance; missing/zero/NaN rejection; invalid weights; Weissman singularity and subunit inversion; Pareto ties and tradeoffs; permutation invariance; disabled dimension tie behavior. No official weight profiles until reviewed.

## Executable metric examples

The [vectors](../conformance/vectors.json) cover totals rather than means of per-file ratios or rates, empty inputs, required values, zero-weight exclusion, unit conversion, overflow/underflow, the historical singularity and inversion, and exact Pareto comparisons. Implement the composite log ratio as a difference of logarithms so that an intermediate quotient cannot overflow before weights are applied. Active dimensions determine exact Pareto dominance. Ordinal UI sorting may use a stable secondary key, while rank equality should depend only on criteria active in the profile.

The checker defines exploratory numeric tolerances for these vectors. Production equivalence, uncertainty-aware dominance and canonical profile identity are unresolved.
